Welcome to the Templating Demo

This is a simple example of Django templating.

Hi, I am {{ person.name }}!

# context Data from views.py.

I am {{ person.age }} years old and I live in {{ person.city }}.

My hobbies are: {{ person.hobbies|join:", " }}.

My Hobbies: ({{ person.hobbies|length }})

# length filter to get the number of hobbies.
    {% for hobby in person.hobbies %}
  • {{ hobby }}
    • {% endfor %}

{% if person.age >= 18 %} I am an adult. {% elif person.age >= 13 %} I am a teenager. {% else %} I am a minor. {% endif %}
